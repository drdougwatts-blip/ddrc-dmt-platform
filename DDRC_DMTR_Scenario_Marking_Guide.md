# DDRC DMT Refresher: Assessed Integrative Scenario

## Marking Guide for Independent Examiner

**RESTRICTED - EXAMINER USE ONLY**

---

The refresher assessed scenario uses the same DCI in Saturation scenario as the full course, with the same marking guide, scoring sheet, and pass/fail criteria. Refresher candidates are experienced DMTs and are expected to perform to the same standard.

The examiner should use the full course Scenario Marking Guide document (DDRC_DMT_Scenario_Marking_Guide) for scoring.

The following adjustments apply to the refresher context:

**Timing:** The refresher scenario window is shorter (approximately 45 minutes total for all candidates, at the end of a long Day 2). Pairs may be assessed in 15-20 minutes rather than 25. Experienced candidates should be able to demonstrate competence more quickly.

**Expectations:** Refresher candidates should need less prompting than full course candidates. An average score of 2.0 remains the pass threshold, but the examiner should note that a score of 2 (competent with minor prompting) from a refresher candidate is less reassuring than the same score from a newly trained DMT. Consistent scores of 1 across multiple areas in a refresher candidate should trigger a discussion with the course director.

**Scenario variations:** Where a refresher course runs alongside a full course, use a different scenario variation for refresher candidates to prevent information sharing. The variations are described in the full course marking guide.

**Result recording:** Use the same scoring sheet from the full course document. Mark as REFRESHER in the header. Results, pass/fail criteria, and documentation requirements are identical.
